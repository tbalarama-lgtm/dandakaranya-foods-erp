BUILD 5 - PYTHON 3.13 LOCAL OCR
================================

Your screenshot error:
  No matching distribution found for rapidocr-onnxruntime>=1.4.0
means Python 3.13 is installed. That old OCR package only supports Python 3.12 and below.

This folder uses the new package names instead:
  pip install rapidocr onnxruntime

Do NOT delete .venv if pdfplumber / openpyxl / pymupdf already installed.
Just double-click this new run.bat.

Windows
1. Keep Python 3.10–3.13 from https://www.python.org/downloads/
   Tick "Add python.exe to PATH" and leave "tcl/tk and IDLE" enabled.
2. Unzip so you can see run.bat in this folder.
3. Double-click run.bat  (Step 1 = PDF/Excel, Step 2 = OCR)
4. Browse File -> your ECI roll PDF
5. Click Start Secure Conversion

First image-roll conversion can take several minutes (OCR model + 45 pages).
Nothing is uploaded.

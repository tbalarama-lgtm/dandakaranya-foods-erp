Secure Local Voter Roll Converter
=================================

Windows
1. Install Python 3.10+ from https://www.python.org/downloads/
   Tick "Add python.exe to PATH" and leave "tcl/tk and IDLE" enabled.
2. Unzip so you can see run.bat in this folder.
3. If a previous try failed, delete the .venv folder in this directory.
4. Double-click run.bat
5. Browse File -> tests\fixtures\sample-electoral-roll.pdf
6. Click Start Secure Conversion

macOS / Linux
  chmod +x run.sh
  ./run.sh
  (Linux: sudo apt install python3 python3-venv python3-tk)

The app stays on your computer. It does not upload files.
Searchable (text) PDFs only. Scanned image rolls are not converted.
